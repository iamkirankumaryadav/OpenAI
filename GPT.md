# GPT (Generative Pre-trained Transformer)

AI model that is pre-trained and understand text and generate new text.

### Generative
- Ability of the model to generate new text that is similar in style and content to the dataset it was trained on.

### Pre-trained
- A pre-trained model is a ML model that has been trained on a large dataset and which can be fine tuned to a new task.
- We don't need to train the models again on a large new dataset from scratch.
- We can directly use an existing model and fine tune according to our own needs.

### Transformer
- A type of a neural network designed to process the natural language text.
- Transformer uses a special technique to transform the words and sentences into a new representation.
- Which captures the important information that is needed to understand the meaning.
- Useful for language translation, question answering, and text generation.
